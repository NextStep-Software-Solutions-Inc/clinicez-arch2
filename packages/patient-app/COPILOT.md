
# Copilot/AI Usage and Contribution Guidelines for This Package

This package is part of the ClinicEZ monorepo. In addition to the root repository guidelines, please follow these package-specific instructions:

## Copilot/AI Usage

- Use GitHub Copilot and other AI tools to assist with code, but always review and understand the generated code before committing.
- Ensure all code (AI or human-written) follows the code style and best practices for this package.
- Document any non-trivial code, especially if generated by AI.

## Code Style & Standards

- Follow the linting and formatting rules defined in this package (see `eslint`, `prettier`, etc.).
- Write clear, maintainable, and well-documented code.
- Add or update tests for all new features and bug fixes.

## Contribution Process

- Open a pull request for all changes. No direct commits to the main branch.
- Describe your changes clearly in the PR description.
- Run all tests and linters before submitting your PR.

## Setup & Development

- See the package `README.md` for setup and development instructions.
- Use the specified package manager (e.g., yarn) for this package.

---

For more details, see the root `CONTRIBUTING.md` in the repository.
## Project Structure & Conventions

- All screen components must be placed in the `screens/` directory.
- All reusable UI components must be placed in the `components/` directory.
- The `app/` directory is reserved strictly for Expo Router file-based routing; do not place screen or component logic here.
