# Contributing to Clinic EZ Monorepo

Thank you for your interest in contributing to the Clinic EZ project! This repository is a monorepo containing multiple projects (packages) with different frameworks and languages. To ensure a high-quality, maintainable codebase, please follow these guidelines:

## General Guidelines

- **Use Conventional Commits** for all commit messages.
- **Open a pull request** for all changes. No direct commits to `main`.
- **Write clear, descriptive PR titles and descriptions.**
- **Adhere to code style and linting rules** for each package. Run linters and formatters before submitting.
- **Add or update tests** for any new features or bug fixes.
- **Document your changes** in the relevant README or documentation files.
- **Respect the structure:** All projects must live under the `packages/` directory.
- **Do not commit `node_modules` or build output.**
- **Use the appropriate package manager** (e.g., yarn, npm) as specified in each package's README.

## Copilot/AI Usage

- Copilot and other AI tools are welcome for code suggestions, but all code must be reviewed and understood by a human before merging.
- Do not commit code you do not understand.
- If using AI-generated code, ensure it adheres to project standards and is properly documented.

## Per-Package Guidelines

Each package may have its own additional contributing guidelines, code style, and setup instructions. Please read the `README.md` and any `CONTRIBUTING.md` in the relevant package before contributing.

## Reporting Issues

- Use GitHub Issues to report bugs, request features, or ask questions.
- Provide as much detail as possible, including steps to reproduce, expected behavior, and screenshots if relevant.

## Code of Conduct

- Be respectful and inclusive.
- Follow the [Contributor Covenant](https://www.contributor-covenant.org/).

---

For questions, open an issue or start a discussion in the repository.
